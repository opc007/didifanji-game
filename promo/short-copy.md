# 项目简介 / Project Short Copy

> 约 150 字,适合官网首屏、README 摘要、Steam 类目简介、众筹页面顶部。

---

《弟弟打姐姐》是一款网页 2D 休闲动作游戏,讲的是弟弟雪地里"偷袭"姐姐的爆笑日常。10 个递进关卡,姐姐会投掷拖鞋、笔记本、痒痒挠,还会翻滚抱枕拍脸;弟弟可以捡雪球、玩具熊、加速鞋、盾牌、磁铁、隐身披风六大道具反击。键盘 / 触屏双操作,原创 8-bit 配乐,本地存档,15 个成就可以解锁,纯浏览器开箱即玩。游戏完全开源(MIT),欢迎加关卡、做音乐、做姐姐新皮肤。**一局三分钟,先笑后挨揍,周末解压神器。**
